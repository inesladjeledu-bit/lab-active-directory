# Lab Active Directory

## Objectif
Mise en place d'un environnement Active Directory complet en local (VirtualBox) pour comprendre l'administration, la sécurisation et l'audit d'un domaine Windows.

## Ce qui a été fait
- Installation et configuration d'un contrôleur de domaine (Windows Server)
- Création d'unités d'organisation, groupes de sécurité et utilisateurs
- Mise en place de stratégies de groupe (GPO)
- Capture et analyse du trafic réseau avec Wireshark (authentification Kerberos, LDAP)
- Identification de mauvaises configurations courantes

## Outils utilisés
VirtualBox, Windows Server, Active Directory, Wireshark
